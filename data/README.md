# data/ — Les pièces du dossier

- `dockets/` — les dossiers JSON publiés (format LS-1.0), immuables une fois FILED.
- `sources/` — les caches bruts sourcés (CourtListener, etc.), avec URI et date de récupération.
- `productions/` — les exports livrés (JSON, BibTeX, impressions).

Règle absolue : un chiffre sans source n'existe pas. Chiffre inventé = banni.
